We’ve shipped v1.5.0 with a new Plane shape, better Model Placer organization, and smoother previews.

## Highlights

-   Plane shape in Shape Builder with Fixed Height and Fixed Depth modes. The fixed dimension is centered around the baseline for intuitive adjustments.
-   Plane settings panel with selectable mode and numeric input for fixed size.
-   Model Placer: Option to place new parts into the same folder as the touching part — keeps results organized alongside source models and plays nicely with Magic Merge.
-   Better segment preview/layout in Template mode when using Start/End Segment %, including gap handling and clamping.
-   Wedge improvements: more robust classification and region cutting for cleaner parts.
-   UX polish: Loading overlays in longer operations to avoid flicker.

See full details in the [Changelog](/docs/11-changelog#150).
